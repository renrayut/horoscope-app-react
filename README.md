# Khmer Horoscope Post Generator

A modern React app to generate beautiful Khmer horoscope posts for Facebook.

## Features
- Upload custom background image (drag & drop supported)
- Select from 12 zodiac animals
- Choose element (Fire, Water, Earth, Metal, Wood)
- Set daily rating (Rising, Falling, Neutral)
- Edit title, subtitle, caption, warning text
- Download as PNG (2x resolution)
- Live preview

## Deploy to Vercel

### Option 1 — Vercel CLI (fastest)
```bash
npm install -g vercel
vercel
```
Follow the prompts. Done in ~1 minute.

### Option 2 — GitHub + Vercel Dashboard
1. Push this folder to a GitHub repo
2. Go to https://vercel.com/new
3. Import the repo
4. Click Deploy — Vercel auto-detects Create React App

## Local Development
```bash
npm install
npm start
```
Opens at http://localhost:3000
